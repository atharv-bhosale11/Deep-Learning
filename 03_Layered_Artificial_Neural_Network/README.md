# Layered Artificial Neural Network (ANN)

## Overview

This folder contains Python implementations demonstrating a Layered Artificial Neural Network (ANN) with an input layer, hidden layer, and output layer.

The programs explain how information flows through different layers of a neural network using forward propagation. They demonstrate weighted sums, bias, ReLU activation, Sigmoid activation, and final predictions.

## Programs 

| Sr. No. | Program Name                                         | Description                                                                                                                                  |
| :-----: | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
|    01   | `01_Layered_Artificial_Neural_Network.py`            | Implements a layered ANN with two input neurons, two hidden neurons, and one output neuron using ReLU and Sigmoid activation functions.      |
|    02   | `02_Layered_Artificial_Neural_Network_Simplified.py` | Demonstrates step-by-step forward propagation, including multiplication, weighted sum calculation, bias addition, and activation functions.  |
|    03   | `03_Layered_Artificial_Neural_Network_Graphical.py`  | Implements ANN forward propagation with graphical visualizations of the network structure, neuron outputs, Sigmoid function, and value flow. |
