# Transformer Architecture

## Overview

This section contains Python implementations and practical demonstrations of Transformer architecture concepts using NumPy.

The programs focus on understanding how Transformers process input sequences using attention mechanisms, calculate relationships between words, and generate contextual representations through Self-Attention and Multi-Head Attention.

## Technologies Used

- Python
- NumPy

## Libraries

```python
import numpy as np
```

## Prerequisites

- Basic Python Programming
- NumPy Fundamentals
- Matrix Operations and Linear Algebra
- Basic Understanding of Neural Networks
- Basic Understanding of Deep Learning

## Learning Objectives

- Understand the fundamentals of Transformer architecture.
- Learn how Self-Attention processes input sequences.
- Understand Query, Key and Value representations.
- Perform manual attention score calculations.
