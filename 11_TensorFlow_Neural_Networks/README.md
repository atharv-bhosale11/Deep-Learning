# 11. TensorFlow Neural Networks

This folder contains practical implementations of Artificial Neural Networks (ANN) using TensorFlow and Keras, covering single neurons, neural network training, and Fashion MNIST image classification.

## 📂 Programs

| Sr. No. | Program Name | Description |
|:---:|---|---|
| 01 | `01_tensorflow_tensor_single_neuron.py` | Implements a single neuron using inputs, weights, bias, and the sigmoid activation function. |
| 02 | `02_tensorflow_tensor_neural_network.py` | Builds, trains, and tests a neural network using TensorFlow and Keras. |
| 03 | `03_tensorflow_tensor_ANN_image_calassification.py` | Implements Fashion MNIST image classification using an Artificial Neural Network. |
| 04 | `04_TensorFlow_Fashion_MNIST_Classification.py` | Implements Fashion MNIST image classification using TensorFlow ANN, including training, evaluation, and prediction. |

## 🧠 Concepts Covered

- Artificial Neural Networks (ANN)
- Artificial Neurons
- Inputs, Weights, and Bias
- Weighted Sum
- Activation Functions
- Sigmoid Activation
- ReLU Activation
- Softmax Activation
- Sequential Neural Networks
- Dense Layers
- Model Compilation and Training
- Model Prediction
- Fashion MNIST Dataset
- Image Preprocessing and Normalization
- Multiclass Image Classification
- Model Evaluation

## 🛠️ Technologies Used

- Python
- TensorFlow

## 📦 Prerequisites

Install the required libraries:

```bash
pip install tensorflow numpy matplotlib
```

## ▶️ How to Run

Navigate to this directory:

```bash
cd 11_TensorFlow_Neural_Networks
```

Run any program:

```bash
python 01_tensorflow_tensor_single_neuron.py
```

Run Fashion MNIST classification:

```bash
python 04_TensorFlow_Fashion_MNIST_Classification.py
```

**Note:** The Fashion MNIST dataset is downloaded automatically through TensorFlow Keras when the program is executed for the first time.

## 🎯 Learning Objectives

- Understand the fundamental structure of artificial neurons.
- Learn how weights and bias contribute to neural network predictions.
- Understand different activation functions.
- Build and train neural networks using TensorFlow and Keras.
- Perform image classification using the Fashion MNIST dataset.
- Evaluate trained models and generate predictions.
