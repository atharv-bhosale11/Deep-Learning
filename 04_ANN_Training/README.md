# 04. ANN Training

This folder contains Python implementations demonstrating the training process of Artificial Neural Networks (ANNs), starting from basic learning steps and progressing to multi-neuron training with graphical visualizations and animation.

The programs demonstrate how an ANN learns by updating weights and how the training process can be visualized step by step.

## 📂 Programs

| Sr. No. | Program                                                    | Description                                                                    |
| ------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 01      | `01_ANN_Trianing_Steps.py`                                 | Demonstrates the basic ANN learning process and weight updates.                |
| 02      | `02_ANN_Trianing_Steps_Graphical.py`                       | Visualizes the basic ANN learning process using graphical representations.     |
| 03      | `03_ANN_MultiNeuron_Trianing_Steps copy.py`                | Demonstrates multi-neuron ANN training with weight updates and visualizations. |
| 04      | `04_ANN_MultiNeuron_Trianing_Steps_Graphical.py`           | Presents multi-neuron ANN training through graphical visualization.            |
| 05      | `05_ANN_MultiNeuron_Trianing_Steps_Graphical_Animation.py` | Demonstrates animated visualization of multi-neuron ANN training.              |

## 🎯 Learning Objectives

Through these programs, you will understand:

* Fundamentals of the ANN training process.
* How neural networks learn from input data.
* The role of weights in neural network learning.
* How weights are updated during training.
* Training processes involving multiple neurons.
* Graphical representation of ANN training.
* Animated visualization of neural network learning.

## 🛠️ Technologies Used

* **Python** – Implementation of ANN training concepts.
* **NumPy** – Numerical computations and array operations.
* **Matplotlib** – Graphical visualization and animation.
