# Deep-Learning

## Overview

This repository contains concept-wise Deep Learning programs implemented in Python.

The programs focus on understanding the fundamental concepts of Deep Learning, including neurons, activation functions, forward propagation and the training process of neural networks.

## Topics Covered

- Artificial Neural Networks Fundamentals
- Biological Neuron vs Artificial Neuron
- Artificial Neuron
- Neural Network Architecture
- Input Layer, Hidden Layer and Output Layer
- Weights and Biases
- Activation Functions
- Sigmoid Activation Function
- Tanh Activation Function
- ReLU Activation Function
- Softmax Activation Function
- Forward Propagation
- Neural Network Training Fundamentals

## Technologies Used

- Python
- NumPy

## Prerequisites

- Basic Python Programming
- NumPy Fundamentals
- Basic Mathematics
- Linear Algebra Fundamentals
- Basic Understanding of Machine Learning

## Learning Objectives

- Understand the fundamentals of Deep Learning.
- Learn how artificial neurons work.
- Understand neural network architecture.
- Explore weights and biases.
- Understand different activation functions and their purpose.
- Learn how forward propagation works.
- Understand how neural networks process input data.
- Develop a conceptual and practical understanding of Deep Learning fundamentals through Python programs.
