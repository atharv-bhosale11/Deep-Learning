# Streamlit – Python Web Applications

This section contains Python programs developed using **Streamlit**, a Python framework for building interactive web applications. It covers basic Streamlit components, user interactions, file uploads, and PDF text extraction.

## 📌 Programs

| Sr. No. | Program Name | Description |
|:---:|---|---|
| 01 | `01_streamlit_JayGanesh.py` | Created a basic Streamlit application with a title and a welcome message. |
| 02 | `02_streamlit_Input.py` | Accepts user input using `st.text_input()` and displays a personalized welcome message. |
| 03 | `03_streamlit_Button.py` | Implements button interaction using `st.button()` and displays a success message. |
| 04 | `04_streamlit_fileUpload.py` | Allows users to upload PDF files using Streamlit's file uploader. |
| 05 | `05_streamlit_TextExtraction.py` | Extracts text from uploaded PDF documents using PyPDF2 and displays it in a text area. |

## 🛠️ Technologies & Libraries

- **Programming Language:** Python
- **Framework:** Streamlit
- **PDF Processing:** PyPDF2

## 📦 Installation

Install the required libraries:

```bash
pip install streamlit PyPDF2
```

## ▶️ How to Run

Navigate to the project directory:

```bash
cd 14_Streamlit
```

Run any Python program using:

```bash
streamlit run filename.py
```

Example:

```bash
streamlit run 05_streamlit_TextExtraction.py
```

The application will open in your default web browser.
