# 10. TensorFlow Fundamentals

This folder contains practical implementations of TensorFlow fundamentals, covering tensor creation, tensor operations, reshaping, variables, and matrix multiplication.

## 📂 Programs

| Sr. No. | Program Name | Description |
|:---:|---|---|
| 01 | `01_tensorflow_tensor_types.py` | Demonstrates scalar, 1D, 2D, and 3D tensor creation and their shapes. |
| 02 | `02_tensorflow_tensor_operations.py` | Demonstrates tensor addition, subtraction, multiplication, division, squaring, sum, and mean operations. |
| 03 | `03_tensorflow_tensor_shape_reshape.py` | Demonstrates reshaping tensors into different dimensions. |
| 04 | `04_tensorflow_tensor_variable.py` | Demonstrates TensorFlow variable creation, assignment, addition, and subtraction. |
| 05 | `05_tensorflow_tensor_matrix_multiplication.py` | Implements matrix multiplication using TensorFlow. |

## 🧠 Concepts Covered

- TensorFlow Fundamentals
- Tensor Creation
- Scalar, Vector, Matrix, and 3D Tensors
- Tensor Shapes and Dimensions
- Tensor Operations
- Tensor Reshaping
- TensorFlow Variables
- Variable Assignment and Updates
- Matrix Multiplication 
- Tensor Arithmetic Operations
- Tensor Aggregation (Sum and Mean)

## 🛠️ Technologies Used

- Python
- TensorFlow

## 📦 Prerequisites

Install TensorFlow:

```bash
pip install tensorflow
```

## ▶️ How to Run

Navigate to this directory:

```bash
cd 10_TensorFlow_Fundamentals
```

Run any program:

```bash
python 01_tensorflow_tensor_types.py
```

## 🎯 Learning Objectives

- Understand TensorFlow tensors and their different dimensions.
- Perform arithmetic operations on tensors.
- Learn tensor reshaping and manipulation.
- Understand TensorFlow variables and their updates.
- Perform matrix multiplication using TensorFlow.
- Develop a foundation for building neural networks with TensorFlow.
