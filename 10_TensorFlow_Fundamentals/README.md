# 10. TensorFlow Fundamentals

This folder contains practical implementations of TensorFlow fundamentals, covering tensor creation, tensor operations, reshaping, variables, matrix multiplication, single neurons, neural network training, binary classification, and Fashion MNIST image classification.

## 📂 Programs

| Sr. No. | Program Name | Description |
|:---:|---|---|
| 01 | `01_tensorflow_tensor_types.py` | Demonstrates the creation of scalar, 1D, 2D, and 3D tensors and their shapes. |
| 02 | `02_tensorflow_tensor_operations.py` | Demonstrates tensor addition, subtraction, multiplication, division, squaring, sum, and mean operations. |
| 03 | `03_tensorflow_tensor_shape_reshape.py` | Demonstrates reshaping tensors into different dimensions. |
| 04 | `04_tensorflow_tensor_variable.py` | Demonstrates TensorFlow variable creation, assignment, addition, and subtraction. |
| 05 | `05_tensorflow_tensor_matrix_multiplication.py` | Implements matrix multiplication using TensorFlow. |
| 06 | `06_tensorflow_tensor_single_neuron.py` | Implements a single neuron using inputs, weights, bias, and the sigmoid activation function. |
| 07 | `07_tensorflow_tensor_neural_network.py` | Builds, trains, and tests a neural network using TensorFlow and Keras. |
| 08 | `08_tensorflow_tensor_calassification.py` | Implements binary classification using a neural network with ReLU and sigmoid activation functions. |
| 09 | `09_tensorflow_tensor_ANN_image_classification.py` | Implements Fashion MNIST image classification using an Artificial Neural Network (ANN). |

## 📦 Prerequisites

Install the required libraries:

```bash
pip install tensorflow numpy matplotlib
```

## ▶️ How to Run

Navigate to this directory:

```bash
cd 10_TensorFlow_Fundamentals
```

Run any program:

```bash
python 01_tensorflow_tensor_types.py
```

To run Fashion MNIST image classification:

```bash
python 09_tensorflow_tensor_ANN_image_classification.py
```

**Note:** The Fashion MNIST dataset is downloaded automatically through TensorFlow Keras when the program is executed for the first time.

## 🎯 Learning Objectives

- Understand TensorFlow tensors and their operations.
- Learn tensor manipulation and matrix computations.
- Understand the working of artificial neurons.
- Build and train neural networks using TensorFlow and Keras.
- Implement binary classification using neural networks.
- Perform image classification using the Fashion MNIST dataset.
- Understand model evaluation and prediction.
